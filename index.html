AI Backups

A personal backup workflow maintained by MRDK80, for preserving AI-assisted development work and continuing it in other environments.

How it works

Local scripts prepare backups of Codex session data and manually downloaded Claude account exports. Archives are encrypted locally with age before being uploaded to the owner's Google Drive using rclone.

The Google OAuth client is a Desktop application for the owner's personal use. It is not a public backup service and does not collect other people's Google credentials.

Google Drive access

The workflow requests the drive.file permission to create and manage its backup files. It does not request full access to all files in Google Drive. Authentication takes place through Google.

Privacy and recovery

This website contains documentation only: no backup archives, authentication tokens or encryption keys. The owner must keep recovery keys separately and check that backups can be restored.
